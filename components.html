Build notes

Reading the file through MCP shows every value, so the gaps show up too. These are the ones found while building, and how the code handles them.

Raw value

Pending text colour

The pending badge text is a raw #f59e0b in Figma while its background is a variable. In code it's one token, --pending.

Raw value

Danger button and dividers

The delete button uses a one-off hex and Settings dividers are white at 10%. Code maps them to the error-subtle token and a single --divider.

Inconsistency

Table header background

bg/200 on Customers, bg/300 on Dashboard. Code uses bg/300 for every table.

Inconsistency

Chart y-axis

User Growth on Analytics runs 0, 0.1k, 0.5k, 1k, 8k, which flattens the line. Code uses the linear scale from Dashboard.

Content

Row count and copy

Customers says "Showing 1–6" over 11 rows, Settings has "DangerZone", and one toast reads "Upload failed! All systems operational". Fixed in code.
